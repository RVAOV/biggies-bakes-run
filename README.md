# Biggie's Bakes Run — published build

`index.html` is the whole game: markup, stylesheet, every JS module and both
images, gzipped and encrypted with AES-256-GCM under a key derived from the
site password (PBKDF2-SHA256, 310,000 iterations).

Nothing here is readable without the password, and there is no password check
in the code to bypass — a wrong key simply fails GCM's authentication tag and
decryption throws.

Do not edit this file. Regenerate it from the project root:

```bash
node build-protected.mjs "<password>"
```
